# 智账 SmartLedger - 个人记账系统

一款类似「随手记」的 Web 版记账应用，支持个人及家庭日常收支管理。

## 🛠 技术栈

- **前端**: Vue 2.7 + Element UI + Vue Router + Vuex + ECharts
- **后端**: Spring Boot 2.7.x + MyBatis-Plus + JWT
- **数据库**: MySQL 5.7

## 🚀 启动指南

1. 确保 Docker Desktop 已启动
2. 在根目录执行：
   ```bash
   docker compose up --build
   ```
3. 等待容器启动完成（首次启动需要下载依赖，请耐心等待）

## 📱 功能特性

- ✅ 用户注册/登录/找回密码
- ✅ 多账本管理
- ✅ 快速记账（收入/支出）
- ✅ 分类管理（支持自定义）
- ✅ 标签管理
- ✅ 记录列表（搜索/筛选/批量删除）
- ✅ 统计报表（趋势图/分类饼图）
- ✅ 预算管理（总预算/分类预算）
- ✅ CSV 数据导出
- ✅ 操作日志
